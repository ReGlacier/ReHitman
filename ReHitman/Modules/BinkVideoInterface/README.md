ReHitman/BinkVideoInterface
---------------------------

A lightweight, independent abstraction layer for interacting with Bink Video (`.bik`) files in game.

**Disclaimer:** This component is an independent implementation and is not affiliated with, endorsed by, or associated with RAD Game Tools or Epic Games.

**No Redistribution:** This repository does not include or distribute `binkw32.dll` or any proprietary Bink Video SDK files.

**Optional Dependency:** This interface is completely **optional**. If `binkw32.dll` is missing from the game directory, the project will still run normally without video playback functionality.
